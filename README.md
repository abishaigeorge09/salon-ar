# salon-ar

AR haircut try-on for salons. iPhone and iPad, front camera, on-device only.

**Paused after the spike, before Phase 1. Read `docs/HANDOFF.md` first** — it records what
exists, what was learned, what is blocked, and what to do on the first day back.

- `docs/HANDOFF.md` — state of play, learnings, roadblocks, next steps
- `docs/BRIEF.md` — scope contract, tagged STATED / INFERRED / PROPOSED
- `docs/adr/` — six architecture decision records, each with a runnable Confirmation
- `docs/PROTOTYPE-REALISM.md` — the week-one test that can kill the product cheaply
- `docs/design/TASTE.md` — annotated references
- `docs/DEBT.md` — known gaps, each with an owner and a trigger

Tier: FULL. It processes biometric data from members of the public who never agreed to anything.
